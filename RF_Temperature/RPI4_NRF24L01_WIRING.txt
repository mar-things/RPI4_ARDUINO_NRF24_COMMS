Raspberry Pi 4 to NRF24L01 wiring
=================================

Use the Raspberry Pi's 3.3V pin only. Do not connect NRF24L01 VCC to 5V.

Current RX_Temperature_RPi.py defaults:
  CE  = GPIO17
  CSN = SPI0 CE0 / GPIO8

NRF24L01 module pins
--------------------

Many NRF24L01 boards use this 2x4 pin layout when looking from above:

          NRF24L01

        +-----+-----+
        | GND | VCC |
        | CE  | CSN |
        | SCK | MOSI|
        | MISO| IRQ |
        +-----+-----+

Some boards print the pin names on the PCB. Trust the printed labels if your
module layout differs.


Wire connections
----------------

        NRF24L01 pin        Raspberry Pi 4 pin
        -----------------------------------------------
        VCC                 Pin 1  - 3.3V
        GND                 Pin 6  - GND
        CE                  Pin 11 - GPIO17
        CSN / CS            Pin 24 - GPIO8  / SPI0 CE0
        SCK                 Pin 23 - GPIO11 / SPI0 SCLK
        MOSI                Pin 19 - GPIO10 / SPI0 MOSI
        MISO                Pin 21 - GPIO9  / SPI0 MISO
        IRQ                 Not connected


ASCII wiring map
----------------

        Raspberry Pi 4                         NRF24L01
        --------------                         --------

        Pin 1   3.3V  -----------------------> VCC
        Pin 6   GND   -----------------------> GND

        Pin 11  GPIO17 ----------------------> CE
        Pin 24  GPIO8  ----------------------> CSN

        Pin 23  GPIO11 / SCLK ---------------> SCK
        Pin 19  GPIO10 / MOSI ---------------> MOSI
        Pin 21  GPIO9  / MISO <--------------- MISO

                                             IRQ unused


Power stability
---------------

NRF24L01 modules are sensitive to weak or noisy 3.3V power.

Recommended:
  - Put a 10uF to 100uF capacitor across NRF24L01 VCC and GND.
  - Keep jumper wires short.
  - Use 3.3V logic and 3.3V power only.
  - Do not power the NRF24L01 from 5V.


Raspberry Pi setup check
------------------------

Enable SPI on the Raspberry Pi:

  sudo raspi-config

Then enable:

  Interface Options -> SPI -> Enable

After reboot, this device should exist:

  /dev/spidev0.0

Run the receiver with the default CE/CSN wiring above:

  python3 /home/martin/Desktop/RF_Temperature/RX_Temperature_RPi.py

If you wire CSN to GPIO7 / SPI0 CE1 instead, run:

  python3 /home/martin/Desktop/RF_Temperature/RX_Temperature_RPi.py --csn 1
